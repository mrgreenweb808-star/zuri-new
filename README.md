# ZuriNew

Open `index.html` in a browser. A standalone, responsive local demo inspired by the supplied Woodmart screenshot, with original Zuri photography, copy, and cream/charcoal/gold branding.

Includes collection filters, expandable products, product previews, a temporary selection, collection search, hero image switching, mobile navigation, and a newsletter demonstration. No backend, checkout, or email service is connected. Only the supplied Kaleido price is shown; other prices remain unconfirmed. Fonts use Google Fonts with local system fallbacks. All product photography is included in `assets/`.
